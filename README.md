# CIT-223-041-2025-DSA-task3-Assignment-

This repository contains the C programming solutions for the programming questions in the Multimedia University of Kenya CCS 2214 assignment.

## Source files

- `question1_circular_queue.c` – Circular queue operations.
- `question4a_sum.c` – Recursive sum of the first N natural numbers.
- `question4b_factorial.c` – Recursive factorial.
- `question4c_fibonacci_term.c` – Recursive calculation of an Nth Fibonacci term.
- `question4d_fibonacci_series.c` – Recursive generation of N Fibonacci terms.
- `question5_queue.c` – Linear queue enqueue and dequeue operations.
- `question6_sparse_matrix.c` – Sparse matrix triplet representation using arrays.
- `question7_deque.c` – Double-ended queue operations using a circular array.

## Requirements

A C compiler such as GCC or the compiler included with Code::Blocks.

## Compile and run

Using GCC, compile a file with:

```bash
gcc question1_circular_queue.c -o question1
```

Then run it:

- Windows: `question1.exe`
- Linux/macOS: `./question1`

Replace the filename and output name to compile a different program.

## Notes

Each source file contains its own `main()` function and should be compiled separately.
